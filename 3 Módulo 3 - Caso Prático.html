Como agir com segurança

Orientação 1 de 4

  1. Não clique, baixe nem pague. Não informe dados pessoais ou bancários.
  2. Feche a aba do navegador. Se não conseguir, feche o navegador pelo sistema; não use os botões do alerta.
  3. Faça uma verificação abrindo manualmente a ferramenta de segurança já instalada no computador.
  4. Peça ajuda por canais oficiais de suporte técnico se a mensagem continuar ou se tiver dúvidas.

E se você já clicou ou pagou?

Não abra o arquivo baixado nem faça novos pagamentos. Se informou uma senha, troque-a acessando o serviço pelo endereço oficial e encerre sessões desconhecidas. Se forneceu dados financeiros, contate seu banco pelo canal oficial. Avise o suporte técnico; se executou um arquivo, pare de usar o computador para operações sensíveis até receber orientação.

Na dúvida, pare. Verifique por um caminho confiável. Só então aja.
